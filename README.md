# Surge-Diversion-Rules

Surge routing / diversion ruleset by Xiaomai.

## Files

- `Surge-Xiaomai.conf` — main Surge profile (subscription placeholder: 你的订阅)
- `Surge-Xiaomai-AdBlock.sgmodule` — ad-blocking module
- `rule-map.html` — interactive rule map (open in a browser)

## Setup

1. Replace `你的订阅` in `Surge-Xiaomai.conf` (`policy-path`) with your Surge subscription URL.
2. Change `your-subscribe-host.example` to your subscription host for DIRECT.
3. Import the `.conf` and enable the `.sgmodule` in Surge.
4. Open `rule-map.html` locally in Chrome / Safari / Edge to explore the rule graph.
